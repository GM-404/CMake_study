# 二、lseek、mkdir、opendir、closedir、readdir 学习笔记
## 1. lseek 函数
功能：修改文件描述符的当前读写位置（偏移量），实现文件内的随机定位。
头文件：
```c
#include <sys/types.h>
#include <unistd.h>
```

原型：off_t lseek(int fd, off_t offset, int whence);
参数：
fd：目标文件的文件描述符。
offset：偏移量（正数向后偏移，负数向前偏移）。
whence：偏移的参考位置，可选值：
- SEEK_SET：从文件开头计算偏移。
- SEEK_CUR：从当前读写位置计算偏移。
- SEEK_END：从文件末尾计算偏移。

返回值：成功返回新的偏移量（相对于文件开头）；失败返回 -1 并设置 errno。

典型用法：
获取文件大小：lseek(fd, 0, SEEK_END)（返回值为文件总长度）。
将读写位置移到文件开头：lseek(fd, 0, SEEK_SET)。

## 2. mkdir 函数
功能：创建新目录。
头文件：
```c
#include <sys/stat.h>
#include <sys/types.h>
```

原型：int mkdir(const char *pathname, mode_t mode);
参数：
pathname：要创建的目录的路径名。
mode：目录的权限模式（如 S_IRWXU 表示所有者 “读、写、执行” 权限），最终权限受进程 umask 影响。

返回值：成功返回 0；失败返回 -1 并设置 errno（如目录已存在、权限不足等）。
注意：mkdir 只能创建单级目录；若要创建多级目录（如 a/b/c），需逐级创建或结合其他逻辑实现递归创建。

## 3. opendir 函数
功能：打开一个目录，返回用于遍历的目录流。
头文件：
```c
#include <dirent.h>
```
原型：DIR *opendir(const char *name);
参数：name 为要打开的目录路径名。
返回值：成功返回指向 DIR 结构的指针（目录流）；失败返回 NULL 并设置 errno。

## 4. closedir 函数
功能：关闭由 opendir 打开的目录流，释放资源。
头文件：#include <dirent.h>
原型：int closedir(DIR *dirp);
参数：dirp 为 opendir 返回的目录流指针。
返回值：成功返回 0；失败返回 -1 并设置 errno。
注意：遍历目录后必须调用 closedir，否则会导致资源泄漏。

## 5. readdir 函数
功能：从目录流中读取一个目录项（目录中的文件 / 子目录）。
头文件：
```c 
#include <dirent.h>
```
原型：struct dirent *readdir(DIR *dirp);
参数：dirp 为 opendir 返回的目录流指针。
返回值：成功返回指向 struct dirent 的指针（包含目录项信息，如文件名 d_name）；目录遍历结束或出错时返回 NULL（可通过 errno 区分原因）。

## 结构 struct dirent 关键成员：
ino_t d_ino：文件的 inode 号（用于唯一标识文件）。
char d_name[]：文件名（遍历目录时最常用的成员）。
遍历目录的典型逻辑：
```c
while ((entry = readdir(dir)) != NULL) {
    if (strcmp(entry->d_name, ".") != 0 && strcmp(entry->d_name, "..") != 0) {
        // 处理非“.”和“..”的目录项（即有效文件/子目录）
        printf("%s\n", entry->d_name);
    }
}
```

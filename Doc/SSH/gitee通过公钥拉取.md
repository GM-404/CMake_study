方法一：通过 SSH 公钥授权（推荐）
1. 生成 SSH 密钥对
需要在本地终端执行以下命令生成密钥（一路回车默认即可）：

```bash
ssh-keygen -t ed25519 -C "对方的邮箱地址"
```

生成的密钥文件默认位于：
```
Windows：C:\Users\用户名\.ssh\

macOS/Linux：~/.ssh/
```
其中 id_ed25519.pub 是公钥（需要提供给仓库管理员），id_ed25519 是私钥（需妥善保管，不可泄露）。

2. 管理员获取的公钥内容
-  申请方打开 id_ed25519.pub 文件（可用记事本、VS Code 等工具），复制全部内容（以 ssh-ed25519 开头，以邮箱结尾）。
3. 管理员的 Gitee 仓库中添加对方的公钥

- 管理员进入的仓库主页，点击右上角 「管理」 → 「部署公钥管理」 → 「添加部署公钥」。
- 填写 公钥名称（如对方的用户名），粘贴申请方的公钥内容，勾选「允许推送」（若仅允许拉取，可不勾选），点击「确定」。
此时，申请方即可通过 SSH 地址（git@gitee.com:你的用户名/仓库名.git）克隆或拉取代码。
